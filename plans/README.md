## Findings considered and rejected

Run 1:

- `claudeMcp` removes a server before re-adding it (`modules/home/claude.nix:626-631`): the next switch retries because the current and wanted values differ. Self-healing.
- `jj pr -m` rewrites the description of `@-` (`modules/home/jj-pr/jj-pr.sh:103-104`): intended behavior when `@` is empty.
- "Darwin is not gated before the nightly auto-merge": wrong. `auto-update.yml:129-144` waits on every pull-request check, and `build.yml` includes the darwin job.
- Thin Darwin CI coverage: settled by ADR-0004.
- TODO cluster in `modules/home/claude/search-eval.md`: the hits are benchmark search terms.
- Committed secrets: the scan found none.
- `HashKnownHosts = false` and unsigned commits: maintainer preferences, not defects.
- `command-runner.ts` pipe ordering and the `jev-report` timeout: unverified and dependent on runtime behavior nobody tested.
- `doc-lock.sh` lets an edit through when its tooling errors (`modules/home/doc-lock/doc-lock.sh:185`): the path needs `ast-grep` or `jq` to fail on a supported language, which was not observed. No evidence it happens.
- `cleanup.nix` keeps a second removed-skills list (`modules/home/cleanup.nix:52-60`): the entries are per-project skills pruned from the global pickers, a different purpose from `removedSkillIds`. ADR-0009 keeps skill curation as separate lists.
- Dead paths cited in ADR-0009 and ADR-0010: both ADRs record proposals that were rejected or deferred, so the missing files are expected.

Run 2:

- The auto-switch job and the Nix garbage collector both start at 04:30: no measured harm. Not confirmed as a defect.
- A double `compinit` in the zsh init and the Rime activation order: the Home Manager source was not matched against `flake.lock`. Unconfirmed.
- The repo overlay shadows `zig`, `codex`, `tsrs`, and `typescript` at the top level of `pkgs`: no consumer breaks today.
- `scripts/setup-varlock-env.sh` has no caller: it is a hand-run utility. Kept.
- Splitting all of `claude.nix` at once: rejected in favor of plan 017's three self-contained moves. No test reads the file as text now, so a wider split is no longer blocked.
- Moving every prebuilt package to JSON pins at once: rejected in favor of the plan 019 pilot, because JSON pins change what the merge driver must parse.

Run 3:

- A gap in ADR numbers at 0018: by design. A deleted ADR's number is never reused.
- One shared table for the Ghostty key chords in `ghostty.nix` and `skhd.nix`: the skhd helpers are parked code the maintainer keeps (plan 011).
- One shared helper for every prebuilt-binary package: wait for the plan 019 pilot, as run 2 decided.
