## Recall

`recall` reads the earlier Claude Code, Codex, pi, omp, and Antigravity sessions for the current folder.

- **New session**: When a task continues earlier work in this folder, run `recall brief` before you act. An earlier user correction still binds.
- **Exact detail**: For an earlier error string, path, number, or decision, run `recall grep REGEX`, then `recall show N` for that session's prompts.
- **Receipt**: A hit records a past event. Check live state (files, git, tests) before you rely on it.
