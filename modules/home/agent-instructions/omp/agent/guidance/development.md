# Development routing — OMP adapter

## OMP tools

- **Read**: Use native `read` for text, spans, URLs, and image questions.
- **Search**: The Search section of `~/.omp/agent/AGENTS.md` names the tool for each case.
- **Shell**: Use the shared commands below when native tools cannot answer the task.
- **Spawn**: Use `task` only for independent work smaller than the current task.
